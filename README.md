# Centre-Aware Robust Multimodal Prognosis in Oropharyngeal Cancer

## Research Question

Do PET/CT radiomics add generalisable value beyond clinical variables for recurrence-free survival prediction across unseen centres?

## Dataset

HECKTOR multicentre PET/CT dataset.

## Main Goal

Evaluate whether PET and CT imaging add robust prognostic information beyond strong clinical survival models, especially when testing on unseen centres.

## Main Modalities

- Clinical variables
- PET imaging
- CT imaging
- Tumour masks
- Recurrence-free survival outcomes
- Centre information
